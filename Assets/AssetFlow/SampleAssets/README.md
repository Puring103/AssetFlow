# AssetFlow Sample Assets

This folder contains a small set of third-party sample assets for manually verifying
AssetFlow importer workflows in the Unity Editor.

## Contents

- `Textures/`: PNG textures for `TextureImporter` workflow checks.
- `Models/`: FBX models and their shared texture for `ModelImporter` workflow checks.
- `Audio/`: OGG clips for `AudioImporter` workflow checks.
- `Licenses/`: original license files from each source package.

## Sources

All included assets are from Kenney asset packs distributed under Creative Commons
Zero (CC0):

- Retro Textures Fantasy: https://kenney.nl/assets/retro-textures-fantasy
- Mini Dungeon: https://kenney.nl/assets/mini-dungeon
- RPG Audio: https://kenney.nl/assets/rpg-audio

The files here are intentionally limited to a small representative subset so the
repository stays lightweight while still covering AssetFlow's MVP importer types.
